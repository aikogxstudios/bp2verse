## Lo que ya haces en Blueprints

Este es el patrón clásico de un enemigo en Unreal Engine (el mismo que ves en la
demo de portada de `bp2verse`): creas un **`Blueprint Class`** con la variable
**`Health`** (`Integer`, por defecto `100`) y un **`Custom Event`** o
**`Function`** llamado **`TakeDamage`** (`Amount` como entrada `Integer`). Al
dispararse, calcula `Max(0, Health - Amount)` para no bajar de cero, guarda el
resultado con **`Set Health`**, y pasa por un **`Branch`** (`Health <= 0` o
`Health == 0`) cuyo pin **`True`** llama a **`Print String`** con
`"Guard down"`.

- **Patrón Blueprint:** `Blueprint Class` (`Health = 100`) → `Event TakeDamage`
  (`Amount`) → `Set Health` (`Max (Integer)` de `0` y `Health - Amount`) →
  `Branch` (`Equal (Integer)` `Health == 0`) → `True` → `Print String`
  (`"Guard down"`).
- **Nombres oficiales de nodos (EN):** `Blueprint Class`, `Custom Event` /
  `Function`, `Set` (`Health`), `Subtract` (`Integer - Integer`),
  `Max (Integer)`, `Equal (Integer)`, `Branch`, `Print String`.

La misma lógica, contada dos veces: la cadena de nodos y su forma en Verse.

## Equivalente en Verse

Aquí juntas todo lo del Módulo 0 en una unidad completa: una **`class`**, una
variable de estado `var Health`, un método `TakeDamage`, la función estándar
`Max`, un `if` como `Branch` e instanciación arquetipo `enemy{}`.

**Salida exacta (`verse-js` 0.1.1):**

```text
Guard down
```

**Anotación línea a línea:**

| Línea | Qué hace                                                                                      | Equivalente en Blueprints                                                        |
| ----- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `1`   | `using { /UnrealEngine.com/Temporary/Diagnostics }` habilita `Print`.                          | Acceso al nodo `Print String`.                                                   |
| `3`   | `enemy := class:` define una clase reutilizable llamada `enemy`.                               | Crear un nuevo `Blueprint Class`.                                                |
| `4`   | `var Health : int = 100` declara el campo mutable de vida con valor inicial `100`.             | Variable `Health` (`Integer`) en *My Blueprint* con *Default Value* `100`.        |
| `6`   | `TakeDamage(Amount : int) : void =` define el método que recibe el daño.                       | `Custom Event` o `Function` `TakeDamage` con pin de entrada `Amount` (`Integer`). |
| `7`   | `set Health = Max(0, Health - Amount)` resta `Amount` sin bajar de `0`.                        | `Set Health` conectado a `Max(0, Health - Amount)`.                               |
| `8`   | `if (Health = 0):` comprueba si la vida llegó exactamente a cero.                              | `Branch` conectado a `Equal (Integer)` (`Health == 0`).                           |
| `9`   | `Print("Guard down")` solo se ejecuta cuando el enemigo cae a `0`.                             | `Print String` (`"Guard down"`) conectado al pin `True`.                          |
| `11`  | `E := enemy{}` crea una instancia en memoria usando sintaxis arquetipo `{}`.                   | Instanciar el Blueprint en el nivel (o crear un objeto en runtime).               |
| `12`  | `E.TakeDamage(30)` baja `Health` de `100` a `70`; `if (Health = 0)` falla, así que no imprime.  | Primera llamada al evento `TakeDamage(30)` (sale por `False`).                    |
| `13`  | `E.TakeDamage(90)` calcula `Max(0, 70 - 90) = 0`; `Health = 0` tiene éxito e imprime.           | Segunda llamada `TakeDamage(90)` (entra por `True`).                              |

<Callout lang="es" variant="trap">
  Dos costumbres de Blueprints o C-like rompen este ejemplo al instante:
  primero, **`guard` es una palabra reservada** en Verse, así que escribir
  `guard := class:` falla en compilación (`Syntax error: Unexpected ':='`; usa
  `enemy`, aunque `"Guard down"` dentro de comillas sí es texto válido).
  Segundo, en la condición del `if` la comparación de igualdad se escribe con
  **un solo `=`** (`if (Health = 0):`), nunca `==` (`Syntax error: Unexpected '='`).
</Callout>
